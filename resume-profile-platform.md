# Resume Profile - Platform Architecture

## Senior Software Engineer

Senior Software Engineer with 30+ years of experience designing durable software platforms and integration architectures. Specializes in converting fragmented legacy estates into cohesive systems with strong maintainability, reliability, and security posture. Effective at building foundational services and technical patterns that support long-term delivery speed.

- Platform architecture and service boundaries
- Data model and schema evolution
- Reliability and operational resiliency patterns
- Secure configuration and secrets management
- Azure Key Vault integration patterns
- .NET 6/.NET Core and SQL Server ecosystem
- Migration strategy across interconnected systems
- Technical leadership in complex environments
