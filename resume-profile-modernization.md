# Resume Profile - Enterprise Modernization

## Senior Software Engineer

Senior Software Engineer with 30+ years of experience modernizing business-critical software in high-dependency environments. Proven track record replacing fragile legacy workflows with maintainable, scalable systems while preserving operational continuity. Strong in architecture, migration strategy, and delivery across complex data and integration boundaries.

## Skills Focus

- Legacy modernization and migration planning
- System architecture and refactoring strategy
- High-risk workflow continuity and phased rollout
- .NET 6/.NET Core, ASP.NET MVC, Blazor
- SQL Server and Azure SQL
- Integration-heavy platform design
- Batch processing and operational automation
- Cross-functional technical leadership
